# 旧主域名协议核对（2026-11-12）

本页保留旧协议核对结果。2026-11-13 用户明确确认旧二维码（缺省/显式 v0）及 `x.4mr.cn` 已停用；它们不再属于当前 f → b0/b1 的替换范围，本轮没有修改旧基础设施。

旧入口此前报告 Yii 提交 `c4e088adc7ba17bd5bb640ac31178a122906e002`，与现代 b0 合同不同；当前 Node 不宣称透明兼容该旧协议。活动架构的回归、已完成切换及环境映射见 [验证记录](VALIDATION.md)。

## 已确认的协议差异

| 场景 | 旧 Yii / 现有 v0 小程序 | 当前 Node 候选 |
| --- | --- | --- |
| 创建 v2 支付 | 客户端省略 `file_id`，旧控制器将客户端金额交给支付供应商 | 要求文件编号、归属、价格与订单绑定；缺少编号返回 400 |
| 历史订单查询 | 旧控制器直接返回供应商订单；没有本地文件绑定和支付 `attach` | 无本地绑定或可信成功附件时拒绝解锁 |
| v2 支付通知地址 | 旧控制器生成 `/v1/wechat-pay/notify` | 现代 v2 流程使用对应 v2 通知路径 |
| 旧用户 JWT | v1/player 与 v2/user 共用 HS256，令牌无 `identityDomain` | 校验身份域，旧令牌返回 401；当前小程序可在原 API 重新登录并重试一次 |
| 文件列表 | 调用者传 `unionid`，源 `FileSearch` 使用 `LIKE`，返回裸数组和 Yii 分页 | 按认证用户归属查询，使用现代排序和响应合同 |
| 文件 REST 写入 | 旧路由支持 POST、PATCH、PUT | 现代 Yii 已移除这三个写入动作，Node 保留其 404 |
| 历史文件价格 | 旧表无 `file.price`、无文件支付订单账本 | 现代表有价格快照和订单绑定；历史价格无法从当前配置可靠推断 |

旧客户端订单号仅由时间与随机数组成，不能恢复文件编号。旧本地购买缓存也不能证明服务端支付归属。这里记录实际差异，不会把缺少的文件、价格或历史订单关系猜测为有效数据。

旧 PHP 的部分宽松输入、跨身份域令牌和任意 unionid 搜索是独立的权限决策；离线执行这些输入仅用于发现源行为，不会据此修改线上认证配置。用户已排除旧入口，并分别批准 b0、b1 延续原 Yii 的设备免签策略，不再等待上述确认。

## 可复跑的本地证据

`scripts/legacy-differential` 仅提供测试工具，不被服务入口加载。准备过程从本地相邻 `game` 仓库读取固定 Git 对象，不获取网络内容，不切换或修改 `game` 工作树。输出均在 Git 忽略的 `runtime/legacy-main-source-20261112`。

```sh
python3 scripts/legacy-differential/prepare-source.py
python3 scripts/legacy-differential/check-oracle.py
node --import tsx scripts/legacy-differential/compare-old-main.ts
node --import tsx scripts/legacy-differential/schema-rehearsal.ts
```

前两个命令需要本地 PHP、相邻 `game` 的固定提交和已安装且与冻结 lock 一致的 vendor。源码 oracle 校验关键文件哈希，实际调用旧控制器和模型；供应商、签名输出、数据库读取使用合成内存替身，任何外部 SQL 连接或执行都会失败。它不验证认证中间件、真实 SDK 签名、MySQL 排序规则、回调、硬件或外部网络。

Node 对照使用实际路由、认证服务、供应商适配器和专用 MySQL 临时库，供应商传输在内存中签名并返回。存在合同差异时返回 exit 1，并将详细结果写入 `comparison.json`；这表示尚不兼容，不是将差异记为通过。测试支付和列表动作时在适配器边界提供固定用户，旧 Bearer 中间件没有执行；令牌另由实际 Node AuthService 验证。

Node 对照和数据库演练都仅允许本机 `127.0.0.1:33368` 的专用 MySQL，各自创建随机新测试库，最后仅删除本次成功创建的库。数据库演练保留旧列快照并执行现代迁移两次。两者不读取部署环境变量，不连接生产库，也不能证明实际旧服务器的 DDL、备份恢复或跨版本业务兼容。详细产物为 `comparison.json` 与 `schema-rehearsal.json`，均位于上述被忽略的 runtime 目录。

源码冻结完整性、27 项源方法自检、路由清单、Node 对照和数据库演练是不同层次的证据；测试数不得相加称为接口全部通过。真实微信、支付、COS 与设备联调按用户要求延期。
